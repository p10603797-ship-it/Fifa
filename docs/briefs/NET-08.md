# NET-08 — Network simulator and two-instance test harness
Owns: `tools/netsim.ts`, `tests/net/**`. Contracts: src/contracts/input.ts (InputFrame, INPUT_FIELDS), app.ts (TickInputProvider, MatchSetup, SessionControl), tuning T_NET, src/sim/core/serialize.ts (packFrames, serializeState), hash.ts (hashState), clone.ts. Your stub was created by FND-04 (read src/net/*). BRIEF §11 1v1 online: "Build this last. Nothing else may depend on it, and local play must work with the network code removed." Transport is PeerJS (peerjs 1.5.5) over WebRTC data channels with the free public PeerJS broker and default ICE servers, settings in one config object; no keys; only a nickname and inputs are sent; no chat, no accounts. Deterministic lockstep with input delay (3 ticks initially, adaptive 2-8), inputs on an unordered channel with the last 10 frames repeated in every packet, lobby/pause/resync on a reliable channel, late input holds the sim with a small waiting indicator and never guesses, desync guard: state hash every 30 ticks, host sends a snapshot on mismatch, guest hard-syncs, both log seed/tick/inputs. Tests must not touch the public network: inject a fake transport (in-memory pair with configurable latency/jitter/loss from NET-08). Definition of done 5: "Online 1v1 completes a full match in the two-instance harness at 80 ms each way, 20 ms
jitter and 5% loss, with no desync."
Implement: a deterministic network simulator transport pair (seeded latency, jitter, loss, duplication, reordering, bandwidth cap) implementing NET-02's
NetTransport (use NET-02's memoryTransport as a base if present); tools/netsim.ts runs two full peers (lockstep + sim) in one process with scripted/random
human inputs for a full match and reports stalls, max stall, desyncs, resyncs, final hashes equal; tests/net/net-08-*.test.ts runs a short version in CI
(2-minute halves) and the long version behind an env flag.
Tests: the harness itself (identical final hashes; induced desync detected), plus the DoD scenario report numbers.
